# Compatibility / 兼容性

支持 Python >=3.12,<3.13；当前本地环境 Python 3.12.13 / NetworkX 3.7、Node 24.19.0 / npm 10.9.0、Windows Edge。

2026-11-16 本地记录及公开副本复验：313 后端、55 Vitest；浏览器四套分别 15、17、1、2 通过。17 项复用先前 14 项业务断言，不能相加冒充唯一用例数。类型、生产构建、真实 API/CLI 一致性及 OpenAPI 契约本地通过。公开副本使用新建 Python 虚拟环境和 npm ci 独立安装；实际命令见 [测试说明](TESTING.md)。配置 CI 不代表远程运行通过。

真实 n8n 导出授权样本为 0。合成样本覆盖多端口、常见内置/扩展节点形状、选择器、动态表达式、凭证/路径/变量及错误工作流引用，但不证明真实版本/目标环境兼容。未知版本或运行时表达式保持 Unknown；缺少目标仅称 Missing From Import Set。

正式原生部署只要求 Windows、Python 和构建阶段的 Node。未承诺第二台干净主机、其他浏览器或容器运行已验证。没有认证、持久化历史、自动执行或迁移。
