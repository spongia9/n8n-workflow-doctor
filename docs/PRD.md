# Product scope / 产品范围

目标用户为在导入或迁移前审查 n8n 工作流的开发者与运维人员。产品给出可追溯的静态证据、依赖图和人工核查清单，不承诺成功执行或目标兼容。

提供 CLI、本机 Web 诊断台和共享 API，支持 JSON/目录/ZIP、安全限制、规则/风险定位、图与四格式报告。界面以中文为主，README 双语。

范围外：自动迁移、工作流执行、云账号连接、秘密读取、自动修复、数据库/队列、公网账户系统。开发过程不得以减少 unknown 或隐藏风险改善指标。

参见 [路线图](ROADMAP.md)、[API](API.md)、[报告契约](REPORT_FORMAT.md) 和 [安全说明](SECURITY.md)。
