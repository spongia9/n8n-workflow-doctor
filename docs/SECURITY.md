# Security / 安全

## 边界

离线静态分析，不执行工作流、Code、表达式、Shell 或包安装，不连接 n8n 账号、不请求输入 URL、不读取其引用路径或环境变量值。原始输入不修改，CLI 报告不覆盖已有文件。

严格 JSON、输入/深度/数量限制和 ZIP 路径、链接、加密、CRC/解压量检查沿用共享输入层；不把压缩包代码提取并运行。错误使用固定脱敏文字，不输出原始参数或堆栈片段。

名称、ID、凭证引用及参数按白名单/指纹输出。指纹不是秘密加密；低熵标识可能被猜测。用户显式提供的 CLI 来源路径可见，不要在路径中包含秘密。

## Web

服务默认仅监听 127.0.0.1，尚无认证、权限控制和公网隔离；不配置公网转发。Host/Origin 校验、固定本地 CORS、前置字节/期限、完整 multipart 清理和有限同步并发保持。结果最多 8 份、总缓存预算 32 MiB、约 900 秒 TTL，也可能提前淘汰；重启清空，旧 ID 返回 404。上传原文不持久化。

HTML 只从脱敏对象生成，动态文本转义，隐形控制字符显式显示，CSP 禁止脚本/远程资源。预览只在惰性模板中解析，重建显示白名单，使用无权限 iframe，不使用 v-html。

原生静态请求只命中启动时白名单，不根据请求读取本地任意文件；UNC/设备/盘符/穿越不产生文件访问。启停通过生命周期锁与实例标识协作退出，不按 PID 或端口强杀。

## 报告问题

请在公开 issue 中仅提供脱敏说明、规则编号、版本和合成重现，不粘贴真实工作流、凭证、Token、Cookie 或认证 Header。发现可能涉及真实秘密时，先在本地处理并联系维护者，避免公开扩散。
